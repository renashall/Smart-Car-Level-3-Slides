# AI Code Academy — Design System

A unified design system for **AI Code Academy** teaching materials — slides,
lesson screens and course UI. Clean, modern and friendly, built to present
hands-on coding and robotics courses to students.

The flagship course represented here is **Machine Learning with Raspberry Pi
Smart Car (Level 3)**, which teaches Python, electronics and computer vision by building
a Freenove 4WD smart car.

## Find The Right Guide

Read the guide that matches the work before editing files.

| Need to change or understand | Read |
| --- | --- |
| Plan class communication or coach duties: announcements, attendance, certificates, and final project recognition | [Organization.md](content/Organization.md) |
| Choose and place visual assets: the brand logo, hardware images, screenshots, asset folders, and image treatment | [assets/ASSETS.md](assets/ASSETS.md) |
| Write or revise learner-facing copy: voice, tone, vocabulary, examples, steps, and short code excerpts | [CONTENT.md](docs/CONTENT.md) |
| Arrange a slide or interface: canvas, safe area, columns, spacing, cards, controls, shadows, and motion | [LAYOUT.md](guidelines/LAYOUT.md) |
| Apply the palette: brand colors, surfaces, text and border tokens, status colors, and focus or hover states | [COLORS.md](tokens/COLORS.md) |
| Set typography: Rubik and JetBrains Mono, type sizes and weights, italics, heading names, and capitalization | [FONTS.md](assets/fonts/FONTS.md) |
| Find a specific supplied file: the catalog describes each icon, logo, part image, board image, screenshot, and Rubik file | [assets/ASSET-INFO.md](assets/ASSET-INFO.md) |
| Pick an icon for a topic or status and choose its size and light or dark background variant | [ICONS.md](assets/icons/ICONS.md) |

| Locate source files and outputs: tokens, components, slide examples, templates, lesson plans, deck folders, and generated files | [STRUCTURE.md](docs/STRUCTURE.md) |

For a rendered lesson deck, begin with the plan in `content/slide-plans/`, use
`templates/lesson-deck/`, and link `styles.css`. The matching workflow is in
`skills/slide-deck-design/`.
